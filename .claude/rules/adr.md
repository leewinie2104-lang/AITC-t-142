# ADR writing rules

- Keep every Markdown file in `docs/07-adr/` to **60 lines or fewer**.
- Write in plain, concise Vietnamese that a project teammate can understand on first read.
- Prefer short sentences and explain technical terms the first time they appear.
- Keep only the context, decision, consequences, and alternatives needed to understand the choice.
- If the draft exceeds 60 lines, tighten it or link to a relevant document; do not exceed the limit.
