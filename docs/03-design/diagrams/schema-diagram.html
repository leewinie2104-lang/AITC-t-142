All 23 tables of schema app, in 10 panels, plus a view panel

Each panel groups one module so its foreign keys can be drawn column to column. A key to a table in another panel is written as → table beside the column. Tables with more than eight columns show their keys first and say how many columns are hidden; every column is in schema.sql. The dashed box is the view kpi_daily_v, which replaces the earlier table kpi_daily.
