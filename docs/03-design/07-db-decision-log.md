# 07 — Decision log (for team review)

> **Status:** proposal v4 (MVP, 23 tables), 2026-11-18; v3 was 27 tables, v2 was 57 tables (`git show 333b85b:docs/database/02-schema.sql`). Rows touched by [D-31](#0-mvp-scope-decision-d-31) carry a **v3 (D-31)** note, rows touched by [D-32](#d-32) a **v4 (D-32)** note. Every open question from v1 (Q1–Q13 in [01-data-model](01-data-model.md)) and
> every new item found during the follow-up pass has a decision below. **Nothing here is approved by the
> business.** Each value is a starting default chosen to be safe and easy to change.
>
> **How to review:** go top to bottom. Rows are sorted so that **low confidence** and **hard to reverse** come
> first. To change a decision, edit the row and apply the change listed under "What changes". Most rows need
> only a data change (`zone_policy` defaults and `prices`; `retention_rule` and `lpr_source` once restored). Rows marked
> "migration" need an Alembic revision.
>
> **About the sources.** Web research ran through a search tool that returns summaries. Rows say **[read]**
> when the page itself was opened and **[summary]** when only the search summary was available. Nothing in
> this file was tested with real users or BQL staff.

Legend. Confidence: **high** = backed by the repo or a primary legal text; **medium** = backed by credible
secondary sources or strong practice; **low** = a judgement call to replace with real numbers.
Reversibility: **data-only** = change rows, no deploy; **migration** = schema change + deploy;
**irreversible in effect** = once applied, data is gone.
