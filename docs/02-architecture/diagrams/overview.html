Luồng chính

  1. Người dùng → HTTPS → caddy → api (JWT, rồi set_config ngữ cảnh RLS) → Postgres.
  2. api / agent-worker → LLMPort (thay tên, biển số bằng mã giả) → Groq hoặc Bedrock; LLM chỉ gợi ý (BR-14).
  3. Log cổng → N1 → "chỗ vừa trống" qua publish() → W2 gán người đủ điều kiện đầu hàng chờ (ETA ≤ 30 phút).
  4. "Tôi về sớm" → port ETA (mock) → W3 báo người thuê → dời hoặc ở lại; ở lại thì chủ đỗ ô dự phòng (ADR-0014).
  5. Merge main → Actions (OIDC) → ECR → Lightsail tự kéo image sau ≤ 2 phút, lỗi thì quay bản cũ.
  6. Laptop dev → Tailscale → DB dev trên máy runner; merge dev → CI chạy alembic upgrade head.
