Sơ đồ kiến trúc / Thư mục server

ParkSmart AI · Cấu trúc thư mục server

Mỗi thư mục cấp 1 trong server/src/app/ là một module, bên trong luôn có cùng 4 thư mục (ADR-0010). Chi tiết bằng chữ: docs/04-development/01-server-structure.md.

1. Cây thư mục

server/src/app/
├── identity/      # M1  tài khoản, đăng nhập, vai trò
├── eligibility/   # M1  tư cách L1–L4, hạn hiệu lực
├── facility/      # M2  khu, tòa, ô, xe
├── policy/        # M3  nội quy, rule engine (hàm thuần)
├── sharing/       # M4  chia sẻ chỗ, chỗ trống khi xe chủ ra
├── booking/       # M5  hàng chờ, giữ chỗ, chủ về sớm, ETA
├── agreement/     # M6  thỏa thuận, OTP
├── ledger/        # M6  bằng chứng xác nhận
├── payment/       # M7  sổ khoản phí (không QR)
├── access/        # M8  log cổng LPR, quá giờ
├── dispute/       # M10 tranh chấp
├── swap/          # M11 hoán đổi (mức 3)
├── approval/      # M12 hàng chờ BQL duyệt
├── reporting/     # M12 KPI
├── notification/  # M13 thông báo
├── knowledge/     #     nội quy cho RAG (W7)
├── agent/         # M14 chat + workflow W0–W7 (LangGraph)
│   └── workflows/  #     mỗi workflow một thư mục
├── platform/      #     dùng chung: config, db, llm, prompts, queue…
├── main_api.py    #     khởi động api, nối các module
└── main_worker.py #     khởi động worker (arq)
sharing/                 # mọi module đều có 4 thư mục này
├── domain/              # 1. nghiệp vụ thuần, chỉ thư viện chuẩn
│   ├── entity.py
│   ├── errors.py
│   └── ports.py         # interface usecase cần
├── usecase/             # 2. một file = một thao tác
│   └── create_share_slot.py
├── delivery/            # 3. cửa vào từ bên ngoài
│   ├── rest/  router.py · schemas.py
│   └── jobs/  n4_forecast.py
└── infrastructure/      # 4. nói chuyện với DB, dịch vụ ngoài
    └── postgres/  repository.py

2. Chiều gọi

Một requestđi từ ngoài vào trong
deliveryREST / job nhận đầu vào
usecasemột thao tác nghiệp vụ
domainentity, rule, port
infrastructurehiện thực port bằng SQL
main_api.py nối tất cả

Module không import nhau

Cần dữ liệu module khác thì khai báo port trong domain/ports.py; composition root gắn vào.

Chỉ agent/ điều phối

Workflow được gọi usecase của nhiều module; bước [LLM] chỉ gợi ý, rule engine quyết định.

Job nền không gọi LLM

delivery/jobs/ chạy trên queue bg; muốn việc khác xảy ra thì phát sự kiện qua publish().

SQL luôn có tham số

Repository dùng asyncpg với $1, $2…, không ghép chuỗi.
